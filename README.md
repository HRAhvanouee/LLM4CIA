
# 🔗  Engineering Change Impact Analysis with Knowledge Graphs and Agentic LLMs

This repository contains the implementation and resources for our developed Framework **LLM4CIA** to **automated Engineering Change (EC) propagation** and **Change Impact Analysis** in Industry 4.0 environments.


## 📄 Overview

Engineering changes often propagate across multiple engineering disciplines and heterogeneous tools, making manual impact analysis time-consuming and error-prone. This work combines a **semantic Knowledge Graph (KG)** with **agentic Large Language Models (LLMs)** to automate engineering change management.

The proposed framework:

- 🧠 Uses a **Knowledge Graph** to represent semantic relationships between engineering artifacts.
- 🔍 Performs **automated change impact analysis** and identifies affected artifacts.
- 🤖 Uses **agentic LLMs** for semantic reasoning and decision-making.
- 🔄 Supports **automatic propagation and implementation of validated changes**.
- 🔗 Enables a **closed-loop engineering change workflow** across an integrated engineering toolchain.
- 🏭 Is validated through a **Factory-X** use case.
